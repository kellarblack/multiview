M3U + XMLTV

Export an M3U and XMLTV from your provider, Threadfin, xTeVe or a tuner. Add the M3U in Sources → IPTV, then paste the guide URL. Multiview reads the guide locally and shows what is on now.

Local HTTP tuners and IPTV servers need the downloaded build on localhost. Browsers block plain HTTP pages from an HTTPS site.

tuners

HDHomeRun and Tablo work through Threadfin or xTeVe. Plex can export live TV the same way. There is no direct Plex API integration — the M3U is the bridge.

You need a legal playlist. Multiview does not sell or provide channels.
