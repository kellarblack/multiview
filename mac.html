window wall

Use More → Window wall to spread tiles into separate windows, or pop out one tile and keep it above your work. The active audio can stay on the game while you do something else.

keyboard

Arrows move, Enter focuses, 1–4 jump, M mutes, F focuses. The wall is built for a keyboard and a remote, not just a mouse.

download

Want a local copy? Download the beta zip, unzip it and run the start script. It serves on localhost so Twitch and tuner links work, and it keeps your boards on this Mac.

The download is a plain static build. It does not phone home.
